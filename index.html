本機辨識，零等待

每一句都經過台灣正體轉換、全形標點、中英空格。不靠 AI 記得，所以不會突然冒出簡體字。

📖

會學你的詞

把常被聽錯的人名、產品名加進詞典。中文詞自動比對同音字（「城市馬」→「程式碼」），英文詞列出錯法就好。

✦

提示詞隨你改

內建 10 種格式，都可以修改，也能新增自己的，例如「週報」。在「我的資料」填署名、職稱、公司，寫信時自動帶入。

⏱️

AI 慢了也不卡

AI 超過時間沒回來，就直接貼本機處理好的版本，不會讓你乾等。

🧠

每句都留底，和 iPhone 共用

每一次輸入都存成每日 Markdown 和 JSONL，放在 iCloud。提示詞、詞典、我的資料也在同一個資料夾，Mac 和 iPhone 共用。

隱私

你的聲音只在你的 Mac 上

聲音不上傳

錄音和辨識都在本機完成，主轉錄完全不需要網路。

AI 用你自己的 key

只有按 AI 指令時，辨識好的文字會送到你自己的 Gemini API key；不送音訊、視窗標題或網址。

沒有帳號、不蒐集

不用註冊，Atype 不回傳任何資料，紀錄只存在你指定的資料夾。

安裝

五分鐘開始用

下載並拖進「應用程式」

到 Releases 下載 Atype-…-macos-arm64.zip，解壓縮後把 Atype.app 拖進「應用程式」。

第一次打開：按「仍要打開」

Atype 沒有經過 Apple 公證，macOS 會先擋下來。到「系統設定 → 隱私權與安全性」，往下找到 Atype，按「仍要打開」。只需要一次。如果出現「已損毀」，在終端機執行：

xattr -dr com.apple.quarantine /Applications/Atype.app

給麥克風與輔助使用權限

照 App 的指示授權。輔助使用是用來把字貼進其他 App。

下載語音模型（250 MB）

首頁選 SenseVoice Small，下載一次就好。

（選用）填入你的 Gemini API key

到 Google AI Studio 免費建立，貼到「後處理」頁。不填也能用主轉錄，只是沒有 AI 指令。

iPhone 版的安裝方式在 iPhone 頁面。

想自己從原始碼編？

需要 Xcode Command Line Tools、Rust、bun、cmake，第一次約 5 到 10 分鐘。自己編的版本不會被 macOS 擋。

git clone https://github.com/JohnKeng/Atype.git
cd Atype/apps/mac
bun install
bun run app:install
常見問題

問與答

要錢嗎？

Atype 免費。主轉錄完全在本機，不花錢。AI 指令用你自己的 Gemini API key，一個人每天說 3,000 字大約每月 US$0.5，而且 Google 有免費額度。

Intel 的 Mac 可以用嗎？

目前只提供 Apple 晶片（M1 以後）的版本。

可以換熱鍵嗎？

可以。「一般」頁改主轉錄，「後處理」頁改 AI 指令。建議 AI 指令設成主轉錄再加一個鍵，就能說到一半再升級成 AI。

沒網路時怎麼辦？

主轉錄照常運作。AI 指令會在時間到之後，貼上本機處理過的版本。

有 iPhone 版嗎？

有，是一個跟 Typeless 一樣用法的鍵盤。目前沒有提供下載，要用 Xcode 自己編譯，請看 iPhone 頁面。

更新之後貼不上字？

到「系統設定 → 隱私權與安全性 → 輔助使用」，選 Atype 按「−」刪掉，再按「＋」加回 /Applications/Atype.app，然後重開 Atype。
