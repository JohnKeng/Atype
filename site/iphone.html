在任何 App 裡，
用說的打字

Atype 的 iPhone 鍵盤。點麥克風，Atype 收音後自動跳回你正在打字的 App，說完字就插在游標處。辨識在手機本機完成，聲音不上傳。

編譯安裝步驟 原始碼
目前沒有提供下載、也還沒上架 App Store，需要用 Xcode 自己編譯 · iOS 26 以上

點一下就開始，自動回到原本的 App

點鍵盤上的麥克風，Atype 會先開始收音，接著自動跳回你正在打字的 App，停在原本的畫面（任何 App 都可以）。說完再點一次，字就插進去。

連續說不必再跳

用完後麥克風待命幾分鐘（可設定，時間到就真的關掉），這段時間再點麥克風直接開始，不必再切換 App。

右上一鍵切換：手機 ／ ✦ AI

「手機」只在本機辨識，最快；切到「✦ AI」，麥克風亮起彩色框，說完由 AI 修同音錯字與標點，開頭說「回信」「回訊息」「會議記錄」「正式一點」「翻英文」就寫成那個格式。署名、職稱用「我的資料」自動帶入。

收到聲音看得見，說錯可以復原

錄音時點點跟著音量起伏，AI 模式還有旋轉的彩色光圈；插錯了按 ↶ 整段刪掉，再按 ↷ 放回來。

字一定拿得到

鍵盤插字後會確認真的進了輸入框；確認不到就自動複製並提示，長按輸入框貼上即可。插成功的那段不會覆蓋剪貼簿。

在 iPhone 本機辨識

用 Apple 內建的聽寫模型，聲音不上傳。提示詞、詞典、我的資料透過 iCloud 和 Mac 共用。

✦ AI 指令

開頭說要什麼格式

鍵盤右上切到「✦ AI」，簡單講內容或大綱。沒說口令就只修錯字、整理口語；缺的資訊標【待補】，署名、職稱從「我的資料」帶入。

回信正式信件 回訊息LINE、Slack 條列重點整理 會議記錄決議與待辦 待辦勾選清單 公告通知同事 正式一點改書面語氣 翻英文道地英文

提示詞可以在 iPhone 或 Mac 上修改、新增，兩邊透過 iCloud 共用。

隱私

聲音只在你的 iPhone 上

本機辨識

用 iPhone 內建的語音模型（Apple 聽寫辨識或長篇辨識），聲音不上傳。

麥克風用完就關

待命時間可設定（預設 3 分鐘），時間到或按 ✕ 就真的關掉麥克風，不會一直開著、也不影響音樂與藍牙耳機音質。

AI 用你自己的 key

只有切到「✦ AI」時，才會把辨識好的文字（不是聲音）送到你設定的服務（OpenAI 相容格式：Gemini、OpenAI、OpenRouter、Groq…），模型從選單挑，預設 Gemini 3.5 Flash-Lite，約 1 秒。key 只存在 iPhone 的鑰匙圈。

安裝

自己編譯，裝到 iPhone

iPhone 版沒有提供下載。需要一台 Mac、完整的 Xcode 26 以上、XcodeGen（brew install xcodegen），以及一個 Apple 帳號。

下載原始碼並產生專案

git clone https://github.com/JohnKeng/Atype.git
cd Atype/apps/ios
xcodegen generate
open Atype.xcodeproj

換成你的開發者帳號

在 Xcode 選 Atype 與 AtypeKeyboard 兩個 target，「Signing & Capabilities」的 Team 換成你的 Apple 帳號；Bundle ID 若衝突，把 com.atype.ios 改成你自己的（兩個 target 與 App Group 要一起改）。

打開 iPhone 的開發者模式

「設定 → 隱私權與安全性 → 開發者模式」，打開後手機會重新開機。接上 Mac，在 Xcode 選你的 iPhone 按執行。第一次要到「設定 → 一般 → VPN 與裝置管理」信任開發者。

加入 Atype 鍵盤

「設定 → 一般 → 鍵盤 → 鍵盤 → 新增鍵盤」選 Atype，再點進去打開「允許完全取用」（鍵盤才能請 Atype 收音並把字放回來）。

（選用）設定 AI 與共用資料夾

App 的「設定」：填 API key、從選單挑模型，就能用鍵盤右上的「✦ AI」；「和 Mac 共用的資料夾」授權 iCloud 雲碟的 service-db/Atype，提示詞與詞典就和 Mac 共用。

免費 Apple 帳號裝的 App 7 天後會失效，要重新從 Xcode 安裝；付費的 Apple Developer Program 沒有這個限制。

常見問題

問與答

為什麼點麥克風會先跳到 Atype？

Apple 不允許第三方鍵盤使用麥克風，所有語音鍵盤（Typeless、Wispr Flow…）都是由 App 在背景收音。Atype 收音後會自動跳回你原本的 App；待命時間內再點麥克風就不必再跳。

自動跳回支援哪些 App？

所有 App。鍵盤會記下你從哪個 App 點麥克風，Atype 開始收音後直接把那個 App 叫回前景，停在原本的畫面（例如 Claude、ChatGPT 會回到原本的對話，不會另開新的）。少數情況認不出來源 App 時，點左上角「◀」回去即可。

可以在 App 裡直接用嗎？

可以。首頁點麥克風說話，結果會自動複製，也能分享；歷史紀錄依日期分組。

字沒插進去怎麼辦？

少數 App 會默默擋掉鍵盤插入的字。Atype 確認不到時會自動複製並在鍵盤上提示，長按輸入框貼上即可；App 的歷史紀錄也都留著。

手機和 AI 模式差在哪？

「手機」只用 iPhone 本機辨識，說完立刻出字；「✦ AI」多一步讓 AI 修同音錯字（例如「轉案」改成「專案」）並依口令排成格式，大約多 1 秒，需要 API key。

說錯了怎麼辦？

鍵盤左側 ↶ 把剛插入的整段刪掉，↷ 再放回來。

會存錄音檔嗎？

不會。iPhone 版只存文字（App 內的歷史，以及授權後 iCloud 第二大腦裡的 atype.iphone.jsonl 與每日 Markdown）。
